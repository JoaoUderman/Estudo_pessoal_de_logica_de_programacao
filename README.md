# Estudo_pessoal_de_logica_de_programacao
Este repositório reúne exercícios, testes e pequenos códigos que desenvolvi ao longo dos meus estudos de lógica de programação.

A ideia aqui é manter um registro pessoal de diferentes práticas que fiz ao longo do tempo, desde exercícios mais antigos até códigos desenvolvidos durante estudos mais recentes.

O conteúdo pode envolver diferentes linguagens e níveis de complexidade, sempre com foco principalmente na prática de lógica, resolução de problemas e aprendizado de programação.

Este repositório não foi criado com o objetivo de ser um portfólio de projetos finalizados ou apresentar códigos totalmente organizados e documentados. Alguns arquivos são apenas exercícios, testes de conceitos ou soluções que desenvolvi enquanto estudava.

Pretendo continuar adicionando novos exercícios e também manter códigos antigos como forma de acompanhar minha evolução ao longo do tempo.
